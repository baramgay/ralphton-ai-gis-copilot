# 누리맵 추가 독립 감사

사용자의 철저한 재검증 요청에 따라 2026-10-05 운영 사이트와 현재 소스를 다시 검사했다. 기존 고도화 계획의 기능별 완료 기준을 확인하고 새로 재현한 결함을 수정했다.

## 추가 수정

지역 지정 단일 추세가 지역을 제한하지 않았다. 실제 자료에서 ‘진주시 최근 3개월 카드매출 증가하는 동’은 305개 행 중 진주시 밖 275개를 포함했다. 질의의 지역 조건을 추세 계산에 전달해 집계 이후, 추세·제외 수·기저 진단·지도 정규화 이전에 적용한다. 수정 후 진주시 30개 행과 지역 밖 0개, 실제 관측월 2025-10→2025-12를 확인했다. 독립 산술 예제와 화면·CSV·보고서 테스트에서 수정 전 실패와 수정 후 통과를 확인했다.

RAG는 일부 명시 지표 질문에서 생활인구 대신 주간 인구, 야간 인구 대신 주야간 비율, 일시 유입 대신 전입을 먼저 반환했다. 등록 제목·표현의 명시 일치를 본문 언급보다 우선하며, 복합 주제를 더 적게 포함한 단순 주제는 우선하지 않는다. 기존 혼합 점수와 근거 차단은 유지한다. 원격 재정렬에서도 같은 우선순위를 유지하며 API의 `subjectMatchLength`는 이 순서를 설명한다. 클라이언트는 `score`만으로 결과를 다시 정렬하지 않는다.

독립 후속 리뷰에서 ‘진주시 중앙동’이 ‘중앙동’으로 축약되어 다른 시의 같은 동명까지 포함될 수 있음을 확인했다. 공통 지역 필터는 인접 시군구와 읍면동을 한 범위로 결합한다. 같은 동명이 두 시에 반복되는 질의도 모든 위치를 검사하고 각각의 시군구 범위를 유지한다. 떨어진 지역은 기존처럼 별도 범위로 유지한다. 라이브러리 및 실제 화면의 동명이인 반례가 수정 전 실패하고 수정 후 통과했으며 관련 859개 테스트도 통과했다.

## 수치와 사용자 여정

수치 336,002건, 일반 가중평균 8,096건, 원자료 22,373,472행의 신규 값 32,940개를 독립 재검증했다. 운영 자료 21개와 로컬 자료의 SHA-256이 모두 일치했다. 원본 요약은 `nurimap-numerics-final-audit.json`에 보관한다. 추세 교차는 기존 지역 제한을 적용하고 지역 프로파일은 선택한 코드만 계산하므로 같은 결함이 없음을 확인했다.

운영의 390×844·768×1024·1280×800·1440×900에서 기존 검증을 재실행했다. 추가 여정은 검색한 2위 행의 CSV 순위 보존, 검색 0건에서 내보내기 숨김, 검색 해제·새 질의 초기화, 비교와 수동 지표의 공유 복원, 시설 검색 1건의 실제 CSV·A4 보고서 범위 일치를 검사했다. 페이지 오류는 0개였다. 한 새 브라우저에서 임시 지도 전환이 관측됐으나 후속 1440px 진입에서 카카오 지도가 정상 작동했다. 최초 현상의 원인 로그가 없어 원인을 확정하거나 외부 지도 가용성을 보장하지 않는다.

## RAG 결과와 한계

같은 고정 질문에서 상위 1개 정답 포함은 10/14→13/14, 상위 5개는 14/14, 무관·무근거 빈 결과는 10/10이다. 별도 명시 지표 질문 3개와 본문에 오해를 유발하는 단어를 반복한 독립 코퍼스, 태그 가중치·편향 벡터·원격 재정렬 회귀를 확인했다. 검색 200회 표본의 p50은 0.4679ms, p95는 1.3375ms이며 `nurimap-rag-final-audit.json`에 원본을 보관한다. HTTP·모델·렌더링은 제외한 개발자 PC 표본이며 운영 성능 보장이 아니다.

고령 인구 대비 의료 공급 질문은 여전히 넓은 의료 취약 도구가 첫 후보이며 더 정확한 고령 수요 도구는 두 번째다. 등록 제목·표현을 명시하지 않은 ‘다른 시군구 주민이 일시 체류하는 규모’는 여전히 KCB 전입인구를 먼저 반환한다. 명시 지표의 우선순위 수정이 일반 의역의 의미 이해를 보장하지 않으며 해당 사례는 미해결이다. 인구·세대는 합성 자료이고 원격 임베딩은 미설정이다. 실제 생성 모델의 성공 사례를 전체 질문의 정확성으로 확대하지 않는다.

최종 프로덕션 빌드의 데스크톱·모바일 E2E 28개가 통과했다. 로그는 `logs/nurimap-final-audit-complete-unit.log`, `logs/nurimap-final-audit-complete-build.log`, `logs/nurimap-final-audit-release-e2e.log`에 남긴다.

## 운영 반영과 재검증

운영 소스는 `3b861588e4c0589efd9ccbbb60b272cad1b29dc5`, Vercel 배포는 `dpl_F4csnxVuyKQa76TQD4Rk22ffnkRL`이다. 도메인 연결을 보류한 운영 배포에서 health와 세 명시 지표의 첫 근거, 실제 AI 의료 취약 분석, 무관한 질문의 빈 근거를 확인하고 `https://gnbc.site`로 승격했다.

최종 운영에서 검색 33개·파서 8개가 오류 0개로 통과했다. 생성 모델은 ‘가기 힘든 지역’에서 실제 사용되어 `rankHospitalScarcity`와 입력 근거의 인용을 반환했다. 네 화면 크기 검증도 모두 통과했다. 진주시 추세는 CSV 30개 행·보고서 상위 20개 행이 모두 진주시였고 공유 재진입도 같은 지역 범위를 유지했다. ‘진주시 중앙동 최근 3개월 카드매출 증가하는 동’은 실제 자료에서 화면·CSV·보고서·공유 재진입 모두 진주시 중앙동 1개 행만 포함했다. 두 별도 여정의 페이지 오류는 0개다.

진주 공유 검증의 최초 시도는 복원 중 표시되는 초기 결과를 먼저 검사해 실패했다. 실행·공유 복원의 추세 제목을 기다린 다음 실제 행과 내보내기를 확인하도록 검사 순서를 바로잡아 통과했다. 제품 수정으로 처리하거나 실패 결과를 정상 결과로 바꿔 기록하지 않았다. 최종 원본은 `nurimap-final-audit-production.json`에 보관한다.
