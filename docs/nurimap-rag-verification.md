# 누리맵 RAG 검증

2026-10-05, 로컬 검색·파서·API 범위를 검증했다. 외부 모델의 실제 응답 품질과 운영 서버 지연은 이 측정에 포함하지 않았다. 외부 모델 호출 수는 0회이며, 원격 오류·지연·잘못된 지표 선택은 모의 응답으로 검증했다. 운영 HTTP 검증은 별도 통합 검증에서 수행한다.

## 평가 표본과 재현

`tests/fixtures/rag-korean-qa.json`은 구현 전에 사람이 정한 24개 한국어 질문과 기대 문서 ID를 고정한다. 의료 접근성·고령 인구·생활/주야간 인구·매출·소득·대출·독거노인·화재·폐기물·거주이동·유입·격자를 묻는 관련 질문 14개와, 무의미 문자열·일반 상식·미지원 주제·범위 밖 지역 질문 10개를 포함한다. 정답은 검색 순위에서 생성하지 않는다.

`node scripts/verify-rag.mjs after`로 재현한다. 기본 문서 124개, 상위 후보 5개를 평가하며 실제 인용 문맥에 포함된 문서 ID도 별도로 기록한다. 20회 준비 실행 후 같은 24개 질문을 순환하여 200회 측정한다. Node v24.15.0, Windows x64, Intel Core Ultra 5 125U에서 수정 전후 모두 실행했다. 원본 측정값과 질문별 결과는 `nurimap-rag-baseline.json`, `nurimap-rag-after.json`에 보관했다.

| 지표 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 관련 질문 상위 1개 정답 포함 | 10/14 | 10/14 |
| 관련 질문 상위 5개 정답 포함 | 14/14 | 14/14 |
| 무관·무근거 질문 빈 근거 반환 | 0/10 | 10/10 |
| 준비 후 검색 p50 | 4.2575 ms | 0.3793 ms |
| 준비 후 검색 p95 | 5.0352 ms | 0.9413 ms |
| 최초 검색 호출 | 6.1785 ms | 4.7688 ms |

지연은 모듈 로딩 후 검색 함수만 측정하며 HTTP·렌더링·외부 모델 비용은 제외한다. 개선에는 문서 토큰·단어 빈도 캐시와 무근거 조기 종료가 함께 영향을 준다. 관련 질문만의 캐시 효과로 해석할 수 없다. 같은 작업 중 카탈로그의 분모 설명도 수정되었으므로 순위 변화 전체를 단일 최적화에 귀속하지 않는다. 상위 1개 정답률은 여전히 10/14이며, 상위 후보의 문서 포함 여부가 분석 수치의 정확성을 증명하지는 않는다.

## 수정한 계약

단어 근거가 없는 해시 유사도나 태그 가중치만으로 문서를 반환하지 않는다. 범위 밖 지역과 관측하지 않는 실거래가·부동산 시세·날씨·가상화폐 질문은 검색과 파서에서 거절한다. 지역 안 시설명에 다른 지역명이 포함되는 경우는 지역 신호를 확인하여 오탐을 줄인다.

문맥 생성은 줄바꿈까지 포함하여 1,200자 제한을 지킨다. `/api/rag/search`의 `hits`는 전체 검색 후보이며, 각 후보의 `inContext`가 실제 문맥 포함 여부를 표시한다. `citations`는 문맥에 포함된 후보의 ID·제목만 반환한다. 파서는 한 번 조회한 근거를 모델 입력과 응답 메타데이터에 그대로 사용한다. 모델이 제안한 민간 지표는 실제 입력 근거에서 확인된 지표여야 한다. 거주 전입·전출과 일시 유입·유출의 자료 구분도 문서에 반영했다.

원격 임베딩 보강은 근거가 있을 때만 요청한다. 예외나 2초 내 완료되지 않는 보강은 로컬 검색 결과로 돌아오고 원격 사용 여부를 false로 표시한다. 테스트에서는 디스크 임베딩 캐시를 읽거나 쓰지 않아 모의 벡터가 실행 환경의 캐시에 남지 않는다.

## 회귀 검증

의미 없는 질문·미지원 실거래가·단순 태그 점수·문맥을 벗어난 인용·모델의 무근거 지표 선택·멈춘 원격 요청·테스트 캐시 저장에 대해 수정 전 실패를 확인하고 수정 후 통과했다. 기존 관련 질문 회귀 기준은 유지했다.

검증 명령은 다음과 같다.

```powershell
npx vitest run tests/rag tests/api/ai-parse.test.ts tests/api/rag-search.test.ts
npx tsc --noEmit
npx eslint src/lib/rag src/lib/ai/parse-intent.ts src/app/api/rag/search/route.ts tests/rag tests/api/ai-parse.test.ts tests/api/rag-search.test.ts scripts/verify-rag.mjs
```

독립 후속 리뷰에서 공개 분석 도구의 근거 검증, 등록 지표에 붙은 ‘순위·비교’, 지명만 일치하는 무관한 질문을 추가로 수정했다. 공개 도구와 민간 지표 모두 제공된 문맥의 후보로 선택을 제한한다. 기본 코퍼스의 등록 낱말을 캐시하며 지명은 질문의 주제 근거로 사용하지 않는다. 기존 질문 표본과 기대 문서는 유지했다.

최종 11개 파일의 201개 테스트, 타입 검사, 범위 린트가 통과했다. 이 보고서의 검색 결과는 로컬 BM25·해시 방식이며 최종 수정 후 다시 측정했다. 같은 개발자 PC에서 다른 검증 작업도 실행되어 지연 비교는 통제된 성능 보장이 아니다. 운영에서도 키가 없거나 원격 보강이 실패하면 같은 로컬 경로를 사용하며, 실제 원격 성공 여부는 API의 `remoteEmbed`와 `mode`로 확인해야 한다.
