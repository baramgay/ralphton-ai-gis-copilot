시안 05 — 고대비에서 유리를 포기하는 법

오른쪽은 html[data-theme="contrast"]의 같은 셸입니다. 왼쪽은 판정 근거입니다.

유리를 엷게 하는 것이 아니라, 재질 자체를 버립니다.

1. 무엇이 사라지는가

  • backdrop-filter 전부 — 흐림 뒤 평균색 위의 대비는 보증 불가
  • 스페큘러 엣지(--glass-edge) — 밝기 차 13%짜리 1px 선은 구분 신호가 못 됨
  • 모든 그림자 — 깊이 신호를 전부 잃는 대신 테두리로 옮김
  • 반투명 전부 — --glass-bg가 #000으로 붕괴

2. 무엇으로 대체하는가

  • 모든 경계 1px → 2px 순백 (패널 경계·카드·칩·입력창)
  • 선택·활성 = 반전(흰 면 + 검정 글자) 하나로만. 색 강조는 자료(지도)에만 남김
  • 지점 카드의 앰버 왼쪽 선 → 6px 흰 선 (색이 아니라 굵기가 의미를 나름)
  • 점수 막대: 채움 대비가 아니라 흰 테두리 트랙 + 흰 채움 — 길이가 곧 값
  • 포커스 링 3px 순백 + 오프셋 2px

3. 왜 화면이 무너지지 않는가

컴포넌트가 색을 직접 박지 않고 var(--glass-*)·var(--text-*)·var(--border-*)만 쓰도록 유지하면, 고대비 전환은 토큰 값 교체로 끝납니다. 이 파일의 셸은 01번과 같은 마크업에 붕괴 토큰만 얹은 것입니다. 위계는 굵기(600→800)와 크기 계단이 담당합니다.

4. 지도의 단계구분은

알파 청록 채우기는 배경 타일 위에서 대비를 계산할 수 없으므로, 고대비에서는 백색 등치선(경계 강조) + 해칭 패턴으로 바꿉니다. 색으로 값을 말하지 않습니다. 이 파일의 지도는 단순화해 백선과 해칭 두 단계만 보여 줍니다.

5. 검증 방법

모든 텍스트 쌍이 순수 #fff/#000 조합(21:1)이거나 #eee(18.1:1), #ddd(15.5:1)입니다. 반투명이 없으므로 계산이 곧 실측입니다. 수치는 MEASURED.md 표 3에 있습니다.
