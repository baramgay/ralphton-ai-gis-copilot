## 1. 최우선 — 내보내기·공유가 새 기능을 제대로 담는가

이번 세션에 **새 답 형태가 넷** 생겼는데, 내보내기·공유는 한 번도 확인하지 않았다.

- 시군구 합산 결과(공공 지표 11종)
- 고령화 속도(`%p` 단위, 지표 2개를 함께 냄)
- 세대 수(세대당 인구를 함께 냄)
- 안내에 붙는 고지 문구들(값 조건·시군구 불가·추세 불가)

**과거에 정확히 이 자리에서 결함이 났다** — 내보내기가 시군구 결과를 "행정동"이라고
적던 문제가 있었다(`docs/`·위키 참조). 새 답 형태에서 재발했는지 본다.

### 할 일
각 질의를 띄운 뒤 `.prod-surfaces.mjs`가 하듯 네 표면을 전부 확인하라:
CSV · 마크다운 보고서 · 한글(클립보드 표) · 공유 링크.

```
"고령비율 높은 시군구"        → 단위가 "시군구"로 적히는가, 22개인가
"고령비율 상승하는 동"        → %p 단위가 표기되는가, 지표 2개가 다 나오는가
"세대수 많은 동"              → 세대당 인구가 함께 나오는가
"상위 10% 소득 지역"          → 31행이 그대로 나오는가, 아니면 24행으로 잘리는가
"소득 100만원 이상인 동"      → 고지 문구가 보고서에도 남는가
"주말에 사람 몰리는 곳"       → 답이 없는 상태를 내보내면 무엇이 나오는가
```

**공유 링크가 특히 중요하다.** 링크를 새 탭에서 열어 **원본과 같은 답이 복원되는지**
확인하라. 예전에 민간 결과가 공유 링크로 복원되지 않던 결함이 있었다. 시군구 단위와
비율 조건(상위 10%)이 링크에 실려 복원되는지 각각 본다.

## 2. 안내 문구가 서로 부딪히지 않는가

이번 세션에 화면 문구를 많이 늘렸다. 두 개 이상이 동시에 걸릴 때를 아무도 안 봤다.

현재 있는 것:
- 범위 밖 지역("부산은 경남 범위 밖입니다")
- 없는 차원("주말은 이 데이터로 답할 수 없습니다")
- 없는 시설("편의점 위치 데이터가 없습니다")
- 없는 지표("출산율 지표가 없습니다")
- 값 조건 고지(`data-testid="query-caveat"`)
- 시군구 불가("시군구로 합칠 수 없어 행정동 단위로 답했습니다")
- 추세 불가("늘고 주는 변화는 이 지표로 아직 낼 수 없어")

### 할 일
겹치는 질의를 만들어 **무엇이 뜨고 무엇이 사라지는지** 적어라:
```
"부산 주말 편의점 상위 10%"          (범위밖 + 차원 + 시설 + 비율)
"주말에 상위 10% 소득 시군구"         (차원 + 비율 + 시군구)
"의료 취약한 시군구 100만원 이상"      (시군구불가 + 값조건)
"세대수 늘어나는 시군구"              (추세불가 + 시군구)
"출산율 높은 시군구"                  (없는지표 + 시군구)
"학교 근처 1인가구 늘어나는 동"        (시설 + 추세불가)
```

판정 기준:
- **모순되면 실패**. "답할 수 없습니다"와 순위가 함께 보이면 안 된다(멈춤 가드는
  이전 결과를 남기되 `stale-answer-notice`가 떠야 한다 — 그게 뜨는지 확인).
- **더 중요한 것이 덜 중요한 것에 가려지면 실패**. 범위 밖 지역은 값 조건 고지보다
  먼저 보여야 한다.
- 고지가 **여러 줄 쌓여 질의창을 덮으면** 실패다(모바일 390px에서도 확인).

## 3. 시군구 합산 값이 맞는가

`rollupToDistricts()`(`tool-registry.ts`)를 새로 넣었다. **원계열을 더하고 비율은 각
도구가 제 공식으로 다시 낸다** — 읍면동 비율을 평균 내면 인구 100명짜리 면과 5만 명짜리
동이 같은 무게가 되기 때문이다.

### 할 일
1. **개수**: 시군구 질의의 전체 행이 정확히 **22개**인가(기본 20행만 보이므로 "더 보기"를
   눌러 끝까지 세라). 창원 5개 자치구가 따로 나오는가 합쳐지는가 — 어느 쪽이든 **적어라.**
2. **절대량**: "총인구 많은 시군구" 1위의 값이, 그 시군구에 속한 읍면동 인구를 큐브에서
   직접 더한 값과 같은가.
3. **비율**: "고령비율 높은 시군구" 1위 값이
   `Σ고령인구 ÷ Σ총인구 × 100`과 같은가. **읍면동 고령비율의 단순 평균과는 달라야 정상이다**
   — 둘 다 계산해서 어느 쪽과 맞는지 적어라. 단순 평균과 같으면 그게 결함이다.
4. **결측**: "1인가구 많은 시군구"에서, 속한 읍면동 중 하나라도 1인가구가 결측인 시군구는
   순위에서 빠져야 한다(추정하지 않는다 원칙). 빠지는지 확인하라.
5. **지역 한정과 겹칠 때**: "김해 시군구별 인구"는 어떻게 되는가.

## 4. 비율 조건이 단위마다 맞는가

"상위 10%"를 전체 행 수의 10%로 환산한다. 단위마다 모수가 다르다.

```
행정동  305개 → 상위 10% = 31행   (확인됨)
시군구   22개 → 상위 10% = 3행    (미확인)
격자   1267개 → 상위 10% = 127행  (미확인)
```

`"상위 10% 소득 시군구"`, `"격자 소득 상위 10%"`, `"하위 5% 소득 동"` 등으로 확인하라.
올림(`Math.ceil`)이므로 소수점이 나오면 올라간다. 실제 행 수를 세어 적어라.
