## 2. 어기면 되돌리는 규칙

1. **색은 토큰으로만.** 새 컴포넌트에 `text-slate-400` 같은 Tailwind 색 유틸리티를 쓰지 마라.
   테마 전환은 색 유틸리티를 **하나씩 열거해** 덮는 구조라, 열거에 없는 클래스는 조용히
   바탕에 묻힌다(실측 1.24:1, 그런데 빌드·lint·tsc 전부 초록이었다). `var(--text-1..4)`,
   `var(--surface-1..3)`, `var(--border-1/2)`, `var(--accent)`, `var(--accent-soft)`,
   `var(--accent-line)`, `var(--glass-*)` 를 쓴다. 세 테마 모두에 정의돼 있다.
2. **완료 판정은 배포본에서.** 로컬에서 됐다는 것은 증거가 아니다. `vercel --prod` 뒤
   위 검사 스크립트를 배포 URL로 돌려 **종료 코드 0** 을 붙여 보고한다.
3. **파이프로 게이트를 삼키지 마라.** `npm run verify | tail` 은 실패해도 초록으로 보인다.
   로그 파일로 빼고 `echo exit=$?` 로 확인한다.
4. **제품 화면에 개발자 말 금지.** 파일 경로·환경변수 이름·라이브러리 이름(`Supabase`,
   `HIRA`, `CSP`, `DemoMap`)·인증키 얘기를 화면에 쓰지 않는다. 하는 일을 일반어로 쓴다.
5. **낱말.** 「읍면동」이 아니라 **행정동**. 소스 주석에도 쓰지 마라 —
   `tests/analysis/unit-word.test.ts` 가 잡는다. 「의려취약지역」 등 옛 문구 부활 금지.
6. **최소 변경.** 지시에 없는 리팩터·정리 금지.
7. **가드는 깨뜨려 봐야 가드다.** 새로 만든 검사는 일부러 결함을 넣어 **붉어지는 것을 확인**한 뒤
   되돌린다. 초록불은 "위반 없음"과 "검사가 못 봄"을 구분하지 못한다.
8. **목록을 손으로 적지 마라.** 레이어·지표는 `catalog.ts` 에서 파생시킨다(§3-2가 그 사고다).

## 3. 이미 끝난 것 — 다시 하지 마라

커밋 `c7c49d7` 로 들어가 있다. 게이트 초록(유닛 1,748 · tsc · lint · build · e2e 18).

1. **지표 고르기를 콤보박스에서 칩 줄로 바꾸고, 고른 레이어 버튼 **바로 아래**로 옮겼다.**

   유입인구밖에 없다」로 읽혔다 — 유출인구도 순유입도 그 상자 안에 있었는데 상자가 안 보였다.
   새 클래스 `.metric-picker` / `.metric-chips` / `.metric-chip`(전부 토큰).
   `layer-switcher.tsx` 에 `activeSlot` prop 추가.
2. **레이어 목록 14 → 22.** `LAYER_OPTIONS` 를 손으로 적고 있어서 KOSIS 여덟 레이어가
   빠져 있었다. 「활용 데이터」 탭은 22개라 적는데 「직접 고르기」에는 14개만 나왔고,
   남은 여덟은 질문으로만 닿을 수 있었다. 이제 `CROSS_CANDIDATE_LAYERS` 에서 파생한다.
3. **시군구 전용 지표 스냅.** KOSIS 지표는 원자료가 시군구까지만 있어 행정동 셀에 소속

   안내 문구를 붙인다(질의로 들어올 때는 원래 그랬다).

## 4. 지시 업무

각 항목은 **문제 → 왜 → 할 일 → 완료 판정** 이다. 완료 판정에 적힌 수치를 실제로 재서 보고한다.

### 업무 1 — 「분석」 탭을 고르는 자리와 보는 자리로 가른다 (최우선)

**문제(실측, 패널 연 상태).** 배포본 1440×900 에서 왼쪽 패널 스크롤 내용이 **1,877px**,
보이는 높이는 **796px**(2.4배). 모바일 390×844 시트에서는 **1,648px** 내용에 보이는 높이
**348px**(**4.7배**).

**왜.** 레이어 고르기 · 지표 고르기 · 단위 토글 · 지역 검색 · 프리셋 · 결과 · 방법론이
한 통에 쌓여 있다. 그래서 방금 고친 지표 콤보박스도 화면 밖에 있었다. 하나를 옮겨 붙이는
것으로는 같은 일이 다음 요소에서 또 난다.

**할 일.**
- 「분석」 탭을 **고르기 영역**(레이어·지표·단위·지역)과 **결과 영역**으로 나눈다.
- 고르기 영역은 **접히는 구역**으로 만들고, 고른 뒤에는 **한 줄 요약**으로 접힌다.
  예: `이동인구 · 유출인구 · 시군구` 를 누르면 다시 펼쳐진다.
- 결과·방법론은 접힘 아래로 내린다.
- 접힘 상태는 `localStorage` 에 **넣지 마라**(첫 방문자가 접힌 화면을 본다). 세션 안에서만 유지.

**완료 판정.**
- 배포본 1440×900 에서 왼쪽 패널 첫 화면(스크롤 0) 안에 **레이어·지표·단위가 모두 보인다**
  (`getBoundingClientRect` 로 잰다, 잘림 없음).
- 「분석」 탭 스크롤 내용 높이가 데스크톱 **1,200px 이하**, 모바일 **900px 이하**
  (고르기 영역이 접힌 기본 상태 기준).
- 모바일 390×844 에서 시트 기본 스냅으로 지표 칩이 **보인다**.
- `node scripts/verify-panel-scroll.mjs <배포URL>` 종료 코드 0.

### 업무 2 — 레이어 22개를 찾을 수 있게 한다

**문제.** 목록이 22개로 늘었다(§3-2). 2단 묶음(민간/공공 → 제공기관)이라 세로가 길고,
찾는 레이어가 어디 있는지 알려면 훑어야 한다.

**할 일.**
- 레이어 **검색 입력** 하나를 목록 위에 둔다. 레이어 이름뿐 아니라 **지표 이름으로도** 걸린다
  (「유출」을 치면 이동인구가 남는다). 원본은 `catalog.ts` 의 `metrics[].label` 과 `triggers`.
- 결과 0건이면 무엇을 못 찾았는지 문장으로 말한다(빈 화면 금지).
- 검색어가 비면 지금 묶음 그대로 보인다.

**완료 판정.**
- 「유출」 입력 → 이동인구만 남고, 그 레이어의 지표 칩에 유입/유출/순유입 셋이 보인다.
- 「재정」 입력 → KOSIS 재정 레이어가 나온다(손으로 닿을 수 있다는 것의 증명).
- 새 유닛 시험: 검색이 지표 이름으로 걸리는 것 · 0건일 때 안내 문장이 있는 것.

### 업무 3 — 터치 표적을 넓힌다

**문제(실측, 패널 연 상태).** 배포본에서 보이는 표적(`button`·`a`·`role=tab`·`input`) 중
**44×44 미달**이 데스크톱 **76/123개**, 모바일 **67/120개**다. 탭 버튼이 89×36,
「활용가이드」·「활용데이터」가 76×28 이다.

**할 일.**
- 최소 크기를 **44×44 CSS 픽셀**로 올린다(WCAG 2.5.8 최소 24, 권장 44). 시각적 칩 크기를
  키우고 싶지 않으면 `padding` 대신 **투명 히트 영역**(`::before` 확장)을 쓴다.
- 인접 표적 사이 간격 최소 8px.

**완료 판정.**
- 검사 스크립트 `scripts/verify-touch-targets.mjs` 를 새로 만든다. 배포본에서 보이는 모든
  `button`·`a`·`[role="tab"]` 의 **히트 영역**(`elementFromPoint` 로 모서리 네 점 확인)이
  44×44 이상인지 세고, 미달이 있으면 **종료 코드 1**.
- 미달 **0건**. 그리고 이 검사가 실제로 붉어지는 것을 한 번 확인한 뒤 되돌린다(규칙 7).

### 업무 4 — 「지금 보고 있는 것」을 지도 위에서 읽게 한다

**문제.** 지도를 보다가 무엇을 보고 있었는지 알려면 패널로 돌아가야 한다. 특히 지표를
바꿔도 지도만 보고 있으면 무엇이 바뀌었는지 이름이 없다.

**할 일.**
- 지도 왼쪽 위 `.map-chip` 자리에 **레이어 · 지표 · 단위 · 기준월**을 한 줄로 띄운다.
- 유리 요소이므로 `--glass-*` 토큰만 쓴다. 기존 `.map-chip` 규칙을 재사용하고 새 색을 만들지 마라.

**완료 판정.**
- 지표를 바꾸면 그 줄이 따라 바뀐다(e2e 1건 추가).
- `node scripts/verify-glass.mjs <배포URL>` 종료 코드 0.
- `node scripts/verify-contrast-all.mjs <배포URL>` 세 테마 전건 통과.

### 업무 5 — 첫 화면이 무엇을 하는 곳인지 말하게 한다

**문제.** 기본 활성 레이어가 `medical` 이라 첫 화면의 「직접 고르기」에는 지표 칩이 아예
안 나온다(의료기관은 지표가 하나뿐이라 칩 줄을 감춘다). 처음 온 사람은 지표를 고를 수
있다는 사실 자체를 모른다.

**할 일.**
- 의료기관 레이어에서도 **지표 자리를 비우지 말고**, 그 레이어가 지점 목록이라 지표 선택이
  없다는 것을 한 줄로 말한다.
- 첫 화면에서 「분석」 탭 맨 위에 **무엇을 할 수 있는지 한 줄**(예: 22개 자료를 지도에
  겹쳐 보고, 질문으로 순위를 냅니다)을 둔다. 온보딩 카드와 중복되지 않게.

**완료 판정.** 첫 방문(로컬 저장소 빈 상태)에서 지표 칩 자리 또는 그 안내 문장이 스크롤
없이 보인다.

### 업무 6 — 세 테마에서 다시 잰다

새 UI를 올린 뒤 **반드시**:

```
node scripts/verify-contrast-all.mjs <배포URL>   # 라이트·다크·고대비 × 세 탭 × 두 폭
```

지난번 이 검사가 「1,714개 전부 통과」라고 거짓 보고를 했다. 정규식으로 색을 읽어
Tailwind v4 가 주는 `lab()`·`oklab()` 을 못 읽었고, **하필 테마 열거에서 빠진 것들이 그
표기로 왔다** — 실제로는 279건 미달이었다. 지금은 캔버스로 읽는다. 이 스크립트를 고치지 마라.

**완료 판정.** 미달 0건. 잰 글자 수를 함께 보고한다(직전 기준 1,513개).

## 5. 제출 방법

- 커밋은 **업무 단위로 하나씩**. 메시지는 한국어로, **무엇이 왜 잘못이었는지** 한 줄 + 본문.
- 각 업무마다 다음 셋을 붙여 보고한다:
  1. `npm run verify` 로그 꼬리와 `exit=0`
  2. 배포 URL과 배포본 검사 스크립트들의 종료 코드
  3. 완료 판정에 적힌 **실측 수치**(before → after)
- 막히면 추측해서 구현하지 말고 멈추고 묻는다.
- 산출물이 있다고 말하기 전에 `ls`·`wc` 로 실제로 있는지 확인한다.
