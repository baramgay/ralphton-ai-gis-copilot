# 누리맵 2·3·4·5차 검증 기록

시작일: 2026-10-05. 사용자 요청에 따라 사용자 여정, 수치 정확성, RAG 근거와 응답 성능을 검증한다. 구현과 로컬 통합 검증을 마쳤으며 운영 검증은 배포 후 기록한다.

## 검증 방법

집계 오류는 소규모 독립 산술 예제와 실제 원자료를 함께 검사한다. 지역 제한 통계는 대상 밖 극단값을 추가해도 계산이 변하지 않는지 확인한다. 분기 추세는 달력 기간과 관측 수를 나눠 확인한다. 실제 공개 자료 21개를 대상으로 유효 수치, 결측·중복 코드, 월 정렬, 시군구 합계와 게시 인구의 총인구÷총면적 관계를 검증한다.

RAG는 독립 한국어 평가셋을 유지하고 관련·무관·무근거·범위 밖 질문을 추가한다. HTTP 검증에는 구현 벤치마크 외의 질문도 포함한다. 문맥에 실제 포함된 문서와 인용 목록이 일치해야 한다. 원격 임베딩과 생성 모델 호출 여부를 구분하며, 로컬 검색 성공을 생성 모델의 사실성 검증으로 표현하지 않는다.

UI 검증은 첫 방문, 키보드 탐색, 검색 0건과 검색 해제, 새 질의, 수동 지표 선택, 지역 비교, 시설 검색, CSV·보고서·공유 복원을 포함한다. 검색된 행도 원래 전체 순위를 유지해야 한다. 390·768·1280·1440px에서 실제 클릭과 키보드 초점을 확인한다.

## 성능 기준값

수정 전 운영 URL을 Chromium의 새로운 브라우저 컨텍스트로 휴대폰·데스크톱 각 3회 진입하고 네 질문을 실행했다. 측정은 개발자 Windows 환경과 일반 네트워크에서 수행하며 브라우저 검증·네트워크 시간을 포함한다. 6회 진입과 24회 질의의 표본이므로 운영 전체 p95 보장으로 해석하지 않는다.

| 항목 | 수정 전 |
| --- | ---: |
| 초기 준비 p50 | 702ms |
| 초기 준비 p95 | 4,004ms |
| 질의 결과 p50 | 288ms |
| 질의 결과 p95 | 642ms |

RAG의 동일 질문·200회 검색 비교는 `nurimap-rag-verification.md`와 수정 전후 JSON에 기록한다. 원자료 재검증은 `nurimap-numeric-verification.md`에 기록한다.

## 최종 로컬 검증

최종 소스의 전체 150개 파일·2,059개 테스트, 프로덕션 빌드와 타입 검사를 통과했다. 전체 ESLint는 오류 0개·기존 경고 47개이며 후속 수정 파일의 범위 린트는 오류·경고 0개다. Playwright E2E 28개가 데스크톱·모바일에서 통과했다. 네 화면 크기의 별도 검증에서도 추천 질문과 네 민간자료 분석, CSV·보고서·공유 복원이 통과했다. localhost는 카카오 지도 허용 도메인이 아니므로 임시 지도 경로를 사용했고, 실제 지도는 운영 도메인에서 확인한다.

실제 자료 검사는 21개 큐브와 운영 게시 인구의 336,002개 검사를 통과했다. NH 원자료 22,373,472행은 별도 Decimal 계산으로 재검증했다. 시설은 실데이터 4,254개이며 인구·세대 합성값의 안내를 유지한다.

로컬 프로덕션 HTTP 검증은 고정 질문 24개와 별도 수용 질문 6개, 파서 질문 8개를 모두 통과했다. 요리·작곡처럼 지명만 일치하는 무관한 질문은 빈 근거를 반환한다. ‘가기 힘든 지역’은 실제 생성 모델을 호출해 `rankHospitalScarcity`와 입력 문맥에 포함된 인용을 반환했다. 나머지 파서 사례는 규칙 경로다. 운영 원격 임베딩은 설정되지 않았으며 성공 모델 품질을 검증했다고 주장하지 않는다.

독립 리뷰에서 감소 추세 보고서의 순위 방향, 늦은 자료·AI 응답의 새 분석 덮어쓰기, 키보드의 요청 순위 범위, 공개 도구의 근거 검증을 추가로 해결했다. 애니메이션 중 강제 클릭을 하던 E2E 도우미는 정상 클릭으로 바꾸고 반복 검증했다.

## 운영 측정 후 보완

첫 통합 배포 `8528d41`의 운영 화면 검증과 RAG 검색 30개·파서 6개는 통과했다. 같은 브라우저 표본에서 초기 준비 p50/p95는 1,170/2,783ms, 질의 결과 p50/p95는 367/1,281ms였다. 네트워크 차이로 인과를 단정하지 않았지만, 실제 모든 표본에서 자료 21개를 함께 요청하고 약 2.37MB를 전송하는 것을 확인했다.

배경 자료는 화면 준비 뒤 유휴 시간에 한 개씩 받고, 직접 선택·질의는 배경 대기열을 거치지 않도록 바꿨다. 취소·잘못된 형식 이후의 재조회와 자료 갱신 중 오래된 요청이 새 요청 표시를 지우는 경합을 회귀 테스트로 확인했다. 늦게 로딩된 큐브의 추세 바로가기도 자동으로 이어 실행한다. 정확한 분모를 보존하려고 커진 NH 자료는 그대로 유지한다.

추가 파서 검사에서는 ‘김해에서 딸기 케이크 만드는 방법’이 지명만으로 지역 상세 분석을 실행하던 결함을 발견했다. 카탈로그 선택과 지역 상세 보조 경로를 같은 질문 형태로 제한해 무관한 본문을 거절하고, 지역명 단독·현황·인구 질문과 경남 접두를 유지한다. HTTP 수용 검사에 요리·작곡 파서 사례 2개를 추가했다.
