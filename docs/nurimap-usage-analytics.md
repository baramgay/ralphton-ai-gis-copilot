# 익명 사용 통계 운영

관리자 화면은 `/admin/usage`입니다. 관리자 비밀번호는 작업 PC의 `.vercel/nurimap-usage-admin.txt`에 보관되어 있습니다. 비밀번호를 저장소나 외부 메시지에 복사하지 마세요. 운영 환경의 `NURIMAP_ANALYTICS_ADMIN_SECRET`에 같은 값이 설정되어 있습니다.

방문, 성공한 분석, 내보내기, 공유와 분석에 실제 사용한 데이터 종류를 집계합니다. 일별·주별·월별 표시, 최근 30·90·365일 조회, 데이터별 활용량, CSV 내려받기를 제공합니다. 시간 기준은 한국 표준시입니다. 관리자 세션은 HttpOnly 쿠키로 12시간 유지됩니다.

방문자 수는 하루 동안 같은 브라우저의 중복 방문을 제거한 수입니다. 주별·월별 수는 일별 방문 브라우저 수의 합계이며, 서로 다른 사람의 수가 아닙니다. 여러 기기, 비공개 브라우징, 저장소 삭제 때문에 실제 사람 수와 다를 수 있습니다. Do Not Track을 설정한 브라우저는 집계하지 않습니다. 브라우저 차단이나 통신 실패로 일부 사용이 누락될 수 있으므로 결제·정산용 수치로 사용하지 않습니다.

IP, 사용자 에이전트, 질문 내용, 이메일, 이름, 위치, URL, 리퍼러는 통계 테이블에 저장하지 않습니다. 브라우저의 익명 식별자는 매일 교체하고, 서버는 날짜별 HMAC으로 변환한 중복 제거 값만 저장합니다. 중복 제거 기록은 당일과 전일분만 유지하며 다음 수집 때 정리합니다. 일별 합계는 유지합니다. 플랫폼 자체의 인프라 로그는 별도의 서비스 정책을 따릅니다.

통계 테이블과 집계 함수는 Supabase의 공개 역할에서 접근할 수 없습니다. 서버의 service_role만 사용합니다. 데이터베이스 장애 시 대시보드는 오류를 표시하며, 0으로 위장하지 않습니다. 분석 기능은 통계 수집 실패와 독립적으로 동작합니다.

비밀번호를 교체하려면 충분히 긴 임의 값(32자 이상)을 운영 환경 변수에 설정하고 재배포합니다. 기존 관리자 세션은 새 비밀번호에서 무효화됩니다. 이 기능을 위해 Vercel 유료 플랜이나 원격 임베딩을 추가하지 않았습니다.
