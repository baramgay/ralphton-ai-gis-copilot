# 누리맵 자료 탐색·사이드바 개편

전체 자료와 분석 추천을 한꺼번에 나열하던 사이드바를 선택 자료·조건 중심으로 바꿨다. 자료 변경 창은 사람과 이동, 상권과 소비, 소득과 지역경제, 생활과 공공서비스 네 목적에서 시작한다. 전체 23개 자료의 출처를 유지하며 지표 이름·트리거 검색도 지원한다. 선택하면 창이 닫히고 해당 지표 조건이 보인다.

현재 수준·변화 보기·함께 보기에서 선택한 종류의 추천만 표시한다. 의료·인구 빠른 분석과 화면·접근성 설정은 필요할 때 펼친다. 추세·교차·통계 분석은 실제 지표·범위·단위·기간을 표시하며 내부 렌더링용 의료 레이어를 분석 자료로 오인하지 않게 했다. 인구 증가 빠른 분석에서도 인구 조건을 표시하고 의료 반경을 숨긴다. 수동 자료 변경 후 전체 범위로 돌아가는 기존 실행 의미를 유지하면서 이전 실행 질문만 비우고 작성 중인 질문은 보존한다.

파비콘과 로고는 파란 바탕과 흰색 N으로 통일했다. SVG, ICO 16/32/48px, PNG 96px, iOS 180px를 제공한다. 버전 URL로 캐시를 갱신하고 잠금 화면에서도 브랜드·홈 화면 아이콘을 제공한다. 아이콘 외 비공개 경로는 계속 잠긴다.

새 의존성, 원격 임베딩, 유료 Vercel 기능을 추가하지 않았다. 수치 계산·질문 해석·내보내기·익명 집계 API는 유지한다. 자동 UI 운영 검증은 사용 이벤트 전송을 가로채 실제 방문·사용 통계를 늘리지 않는다. 운영 익명 로그 기능 자체의 검증은 앞선 배포 기록을 참고한다.

## 검증

최종 전체 단위 테스트 165개 파일 2,248개가 통과했다. 앱 조건·키보드와 고령 의료 지표 회귀 테스트를 포함한다. 타입 검사와 프로덕션 빌드가 통과했으며 전체 lint는 오류 0개·기존 경고 47개였다. 변경 파일 검사도 오류가 없었다.

브라우저 E2E 30개와 390/768/1280/1440px × 밝은/어두운/고대비 12개 화면 조건이 통과했다. 네 목적에 23개 자료가 중복·누락 없이 포함되고, 유출 검색·지표 변경·선택 1회 실행·Escape 취소·포커스 복귀·Tab 경계를 검증했다. 각 화면의 탐색 창이 viewport 안에 있고 가로 넘침과 브라우저 오류가 없었다. 실제 16/32px 아이콘과 모바일·데스크톱 화면을 이미지로 확인했다. 모달에서 단축키가 배경 패널을 변경하지 않고 Escape 후 열린 패널과 변경 버튼 포커스가 유지되는 실제 브라우저 회귀도 통과했다.

독립 수치 대조 336,002개 검사·21개 자료·22개 시군구 밀도 집계에서 실패 0건이었다. 로컬 HTTP RAG 검색 42문항·parser 8문항도 실패 0건이었다.

재현 명령은 `npx vitest run --maxWorkers=4`, `npm run build`, `npm run lint`, `npx playwright test`다. 별도 화면 검증은 `UX_VERIFY_URL`을 실행 서버로 설정한 뒤 `node scripts/verify-intuitive-workspace.mjs`로 실행한다. 운영 검증은 `EXPECTED_SHA`를 배포 커밋으로 지정한 뒤 `node scripts/verify-intuitive-production.mjs`로 실행한다. 카카오 타일·확대·드래그, 김해 범위에서 수동 자료 변경, 진주 3개월 추세의 적용 조건, 아이콘 자산과 키보드 취소를 확인한다. 결과는 gitignored `logs/`와 `test-results/`에 남긴다.

## 병렬 리뷰와 운영 확인

첫 운영 배포 44c5684에서 실제 카카오 지도·지역별 선택·추세 시나리오를 검사했다. 모바일 Escape에서 배경 사이드바까지 닫히는 결함을 찾아 모달과 전역 단축키 경계를 수정했다. 리뷰에서 발견한 단위 오인과 이전 질문 잔존도 수정했다. 시군구 집계 코드와 정식 이름을 함께 확인하므로 공백이 있는 창원시의 구와 대표 행정동 코드를 유지하는 시군구 비교를 구분한다. 인구 빠른 분석은 실제 행정동 단위를 표시하고 의료 반경을 지도에서도 숨긴다. 자료·빠른 분석·반경 변경에서 이전 제출 질문만 비우며 새 초안은 유지한다.

고령 의료 분석의 중복 고령인구 비율을 제거해 의료 보조 지표 3개가 각각 한 번씩 표시되도록 했다. 순위와 수치 산식은 유지한다. 회귀 테스트에서 고령 비율·인구 1만 명당 의료기관·최근접 거리·2km 시설 수를 독립 값으로 확인했다. 수정 후 읽기 전용 리뷰에서 보고한 결함이 해소됐음을 확인했다.

44c5684 운영 API 검사에서 RAG 검색 42문항·parser 8문항, 고정 LLM 평가 22문항, 수치 대조 336,002건이 모두 통과했다. 실제 LLM 경로는 5건이었고 HTTP 중앙값 810ms·p95 1,060ms였다. 5건의 관측값이며 SLA나 UI 변경의 속도 개선율로 해석하지 않는다. Node와 브라우저의 AbortSignal을 직접 전달할 수 없어 동일 제한시간의 Chromium HTTP로 실행했으며 TLS 검증은 유지했다. 아이콘 검사는 metadata의 실제 버전 URL을 요청한다. Vercel의 비버전 ICO 캐시 응답 대신 사용자에게 제공하는 동일 URL을 검증한다.

최종 제품 수정본 `bb97f229fb2daf6619d4680cfa816b31171a15f9`를 작업 브랜치와 main에 push했고, `https://gnbc.site/api/health`의 배포 SHA가 일치했다. [CI 37490078914](https://github.com/baramgay/ralphton-ai-gis-copilot/actions/runs/37490078914)가 통과했다. Linux CI는 단위 2,240개 통과·Windows 전용 8개 건너뜀, E2E 30개 통과였다. Windows 로컬에서는 단위 2,248개가 모두 통과했다.

이 수정본의 운영 API를 다시 검사해 RAG 검색 42문항·parser 8문항, 고정 LLM 평가 22문항, 독립 수치 336,002건 모두 실패 0건을 확인했다. 실제 LLM 경로 5건의 HTTP 중앙값은 901ms·p95는 1,022ms였다. 작은 표본의 관측값이며 SLA나 UI 개선에 따른 속도 변화로 해석하지 않는다.

운영 사이트에서 390/768/1280/1440px와 밝은/어두운/고대비 조합 12개를 재검증했다. 별도 1440/390px 사용자 시나리오에서 실제 카카오 타일 24/12개 로드와 확대 반응, 드래그 수행, 김해 생활인구에서 수동 카드소비 선택 시 질문·범위 초기화, 진주 카드매출의 3개월 추세 조건, 모달 Escape·포커스 복귀, 버전 아이콘 4종 HTTP 200을 확인했다. 약국 위치 표시 후 인구 빠른 분석으로 전환하면 이전 질문을 비우고 경남 전체·행정동 조건을 표시하며 의료 반경을 숨겼다. 위치 표시는 분석 완료와 다른 정상 완료 문구를 사용하므로 검증 스크립트도 해당 문구를 명시해 대기한다. 브라우저 오류와 CSP 차단은 0건이었다. 테스트의 사용 이벤트 전송은 가로채 운영 집계를 증가시키지 않았다.
