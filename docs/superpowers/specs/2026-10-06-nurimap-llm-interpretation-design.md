# 기존 LLM 의도 해석 고도화 설계

사용자가 승인한 방향은 원격 임베딩과 Vercel 유료 전환 없이 기존 LLM API를 개선하는 것이다. 규칙이 이미 해석하는 질문은 외부 호출 없이 유지하고, 규칙이 놓치는 표현만 LLM으로 해석한다. 계산과 통계 설명은 기존 검증된 코드와 원자료를 사용한다.

LLM에는 검색 근거에 등록된 도구·민간 지표와 사용자 질문에서 확인한 지역만 제공한다. 스키마뿐 아니라 지역 조건과 도구 근거를 검증한다. 동명이동은 자동 선택하지 않고 정식 지역을 포함한 질문을 제안한다. UI의 직접 레이어 처리도 같은 지역 확인을 먼저 거친다.

DeepSeek 요청에서 공식 thinking 비활성화 필드를 사용하고 JSON 출력 길이를 제한한다. 최대 2회·총 15초의 모델 요청 예산을 적용하며, 잘못된 응답에는 짧은 검증 오류를 전달하는 보정 요청을 한다. 자동으로 더 비싼 모델로 올리지 않는다. 자격·엔드포인트 오류는 즉시 종료한다.

검증은 기존 회귀 검사와 새로운 지역·스키마·응답 보정·시간 제한 테스트를 포함한다. 실제 HTTP 질문을 고정하여 변경 전후 결과와 지연을 비교하고 AI 사용 여부를 기록한다. 외부 API 비용은 토큰 사용량 관측과 구분하며 과금 감소율을 추정해서 완료로 보고하지 않는다. 최종 빌드와 CI 후 기존 배포에 반영한다. Vercel 구독·결제수단·EMBED 환경변수·공유 Supabase는 변경하지 않는다.
