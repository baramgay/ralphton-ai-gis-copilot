# 누리맵 2·3·4·5차 고도화 설계

사용자는 2026-10-05 판단을 위임하고 병렬 구현, 사용자 관점 검증, 수치 정확성, RAG 성능과 최적화까지 연속 진행을 요청했다. 기존 앱·데이터·배포 구성을 유지하며 확인한 오류를 중심으로 수정한다. 회원제나 결제는 추가하지 않는다.

## 선택한 접근

시각 스타일만 바꾸면 질의·수치·근거 오류가 남는다. 전면 재구축은 검증된 GIS 기능을 다시 검증해야 한다. 기존 기능을 수정하고 독립 계산 사례와 사용자 여정을 확장하는 방식으로 진행한다.

## 2차: 질의와 사용자 흐름

상관·이상치 분석이 요청한 지역과 행정 단위를 실제 계산에 적용하도록 한다. 첫 분석 전 방향키가 임의 지역을 선택하지 않고 현재 결과 순위만 탐색하도록 한다. 닫힌 패널의 컨트롤은 키보드 초점에서 제외한다. 새 분석은 이전 검색 조건을 초기화하고 검색 해제 행동을 제공한다. CSV와 보고서는 화면의 검색 범위와 전체 순위 번호를 유지하며 빈 자료를 내보내지 않는다. 공유 링크는 실행한 분석과 비교 대상을 복원한다. 입력 중인 문장과 이전 실행 결과를 혼동하지 않는다.

## 3차: RAG 근거 품질

해시 임베딩의 우연한 유사도로 무관한 문서를 근거로 제시하지 않는다. 관련 한국어 질문, 유사 표현, 무관한 질문, 근거가 없는 질문을 평가하고 실제 문맥에 포함된 문서만 인용한다. 기존 관련 질문의 검색 품질을 유지하면서 무근거 결과는 빈 근거로 반환한다. 원격 임베딩 실패·지연 시 로컬 경로가 동작하는지도 확인한다. RAG는 계산 엔진의 수치를 새로 계산하거나 대체하지 않는다.

## 4차: 독립 수치 검증

인구밀도는 총인구÷총면적이다. NH 개인 소비비중과 야간 소비비중은 실제 분모를 사용하고, 필요한 분모가 없는 자료는 잘못된 가중평균을 반환하지 않는다. 어댑터가 읽는 원자료에 실제 분모가 있으면 큐브에 보존한다. 기존 별도 작업 파일 `scripts/adapters/nh-blocks.mjs`는 수정하지 않는다. 추세는 관측 횟수와 달력 기간을 구분하고 실제 시작·종료 관측월을 사용한다. 분기 자료 기울기는 실제 월 간격으로 계산한다. 독립 산술 예제, 대상 외 극단값, 결측·0·연도 경계, 화면·공유·파일의 일관성을 검증한다.

## 5차: 측정과 최적화

RAG 검색의 반복 요청 p50·p95를 수정 전후 동일한 질문으로 측정한다. 문서 토큰 등 반복 계산을 재사용할 수 있으면 검색 순서·점수를 유지하며 최적화한다. 실제 브라우저에서 초기 준비, 질의 실행, 요청 수와 오류를 기록한다. 확인되지 않은 병목에 대한 추상화나 새 캐시 인프라는 추가하지 않는다. 결과 수치와 근거 품질을 유지하는 것이 성능보다 우선이다.

## 완료 기준과 제약

- 회귀 테스트는 구현을 복사하지 않고 독립 산술 또는 사용자 요구를 검증한다.
- 390·768·1280·1440px에서 지도·질의·검색·비교·공유·내보내기와 키보드 조작을 검증한다.
- 관련 단위·API·UI 테스트, 전체 테스트, 타입 검사, 린트, 빌드와 운영 검증을 통과한다.
- 공유 Supabase의 다른 서비스 테이블, 실제 원자료, 운영 비밀값은 변경하지 않는다.
- 합성 통계를 실측으로 바꾸거나 없는 분모를 추정하지 않는다.
- 측정 환경과 표본 수를 보고하고 운영 전체 성능 보장으로 해석하지 않는다.
