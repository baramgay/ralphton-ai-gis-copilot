# 사용 통계 대시보드 설계

기존 LLM 해석 개선과 함께 개인정보를 수집하지 않는 사용 통계를 추가한다. 추가 유료 서비스 없이 기존 Supabase와 Vercel Hobby를 사용한다. 대시보드는 우선 관리자 전용으로 구현하며 별도 비밀번호와 서명된 HttpOnly 세션으로 보호한다.

방문 횟수는 앱 페이지 열기, 일별 방문 브라우저는 KST 날짜마다 갱신되는 무작위 브라우저 표식으로 집계한다. 주·월의 방문 브라우저는 일별 합계이므로 '방문 브라우저 일수'로 명명한다. 실제 사람 수나 기간 고유 방문자라고 표시하지 않는다. IP·UA·질문 원문·좌표·선택지역·URL·리퍼러는 통계 테이블에 저장하지 않는다. 서버에 표식을 해시해 중복 제거용으로 최근 2일만 보관하고 새 집계 시 만료분을 삭제한다. 플랫폼 자체의 기본 접근 로그와 앱 사용 통계는 구분한다.

성공한 명시적 분석 1회, 데이터별 분석 사용, 내보내기 요청, 링크 복사를 집계한다. 자동 기본 결과·실패·재렌더는 분석 수에 포함하지 않는다. 복합분석은 분석 1회와 실제 사용한 여러 데이터 종류를 각각 집계한다. 이벤트 UUID로 재전송 중복을 막는다. 수집 실패가 지도·분석을 막지 않게 배치·비동기로 전송한다.

전용 nurimap_usage_daily와 nurimap_usage_receipts 테이블만 추가한다. RLS와 역할별 권한을 검증하고 익명 DB 접근은 차단한다. 기존 프로젝트의 다른 앱 테이블은 변경하지 않는다. DB 함수의 원자적 집계와 트랜잭션 롤백 검사로 중복·합계를 검증한다.

관리 화면은 KPI, 일·주·월 추이, 데이터별 사용 순위, 표와 CSV를 제공한다. 최근 30·90·365일의 조회 범위를 제한하고 KST·월요일 주 시작·월 1일을 표시한다. 실제 기록이 없는 경우 빈 상태를, 설정·조회 오류는 오류 상태를 보여 주며 임의 예시 숫자를 넣지 않는다. 브라우저 표식 삭제·차단·여러 기기·자동 요청에 따른 오차를 명시한다.
