# 누리맵 분석 작업 화면 전면 개편

## 목적

사용자는 자료 이름이나 제공기관을 몰라도 목적을 고르고 분석할 수 있어야 한다. 사이드바는 현재 선택과 실행 조건을 설명하고, 전체 자료 목록과 고급 기능을 동시에 나열하지 않는다. 사용자 위임에 따라 공공·민간 분석을 균형 있게 배치한다.

## 화면 구조

질문 입력은 간결한 상단 작업 영역에서 유지한다. 왼쪽 패널은 선택 자료, 현재 지표·지역·단위·기간, 분석 방식 순으로 구성한다. 전체 23개 자료는 별도 탐색 창에서 사람·이동, 상권·소비, 소득·경제, 생활·공공서비스 목적별로 찾는다. 제공기관은 각 자료의 출처로 표시한다. 기존 지표 이름·구어체 검색을 유지한다.

자료를 고르면 탐색 창이 닫히고 해당 지표 조건이 보인다. 변화와 교차 분석은 분석 방식에서 선택한 목록만 보인다. 전문 분석과 화면 설정은 필요할 때 펼친다. 현재 실행한 결과와 무관한 의료 조건을 표시하지 않는다. 수동 자료 변경으로 지역 범위가 바뀌면 현재 범위를 표시하고 이전 질문이 결과의 설명처럼 남지 않게 한다.

로고와 파비콘은 파란 바탕과 굵은 흰색 N 지도 모티프로 통일한다. SVG, ICO 16/32/48px, PNG 96px, iOS 180px를 제공하고 버전 URL로 캐시를 갱신한다.

## 보존 범위

수치 계산, 데이터 출처·기준월, RAG/LLM 해석, 지역 확인, 분석 실행·취소, 공유 복원, 내보내기, 익명 집계를 유지한다. Vercel 유료 기능이나 새 의존성을 추가하지 않는다. 카카오 지도 CDN 허용을 보존한다. 사용자 소유 파일은 변경하지 않는다.

## 성공 기준

첫 화면에 전체 제공기관·자료 목록이 노출되지 않는다. 목적이나 검색으로 23개 자료 모두에 접근할 수 있다. 유출 검색과 이동인구 지표 변경, 시군구 전용 지표, 공공 분석, 추세·교차 분석과 내보내기가 동작한다. 질문 실행 결과의 실제 자료·지역·기간이 사이드바와 일치한다. 모달의 Escape·포커스 복귀·키보드 탐색이 동작한다. 390/768/1280/1440px와 세 테마에서 지도·조건·결과가 겹치지 않고 스크롤할 수 있다. 아이콘을 16/32px 실제 크기로 확인한다. 전체 검사와 운영 배포 후 동일한 사용자 시나리오를 검증한다.
