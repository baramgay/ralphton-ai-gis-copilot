# 실제 지도 위 데스크톱 사이드바

이전 틴트 변경은 데스크톱의 별도 그리드 칸 뒤에 지도가 없어 눈에 띄는 투명 효과를 만들지 못했다. 사용자는 실제 지도가 비치는 데스크톱 사이드바와 https://rescene.gnbc.site/의 패널을 요청했다. 참고 화면은 전체 지도 위에 여백과 둥근 모서리가 있는 반투명 패널을 놓고 있으며, 실제 DOM에서 밝은 패널 배경 50%와 backdrop 흐림을 확인했다.

지도는 작업 공간 전체 너비에 깔고 기존 양쪽 패널 칸 위에 사이드바를 겹친다. 밝음 틴트는 52%, 어두움은 64%, 흐림은 20px이다. 강한 본문 색을 보조 글자에도 적용하고 입력·수치 읽는 면은 유지한다. 패널 외곽에 12px 여백과 18px 모서리를 적용한다. 저장된 패널 폭·접힘 상태와 모바일 시트 구조는 유지한다.

카카오 setBounds의 상·우·하·좌 패딩을 사용해 현재 열린 패널 너비와 조절선 6px를 제외한 공간에 분석 경계를 맞춘다. 같은 범위와 패널 상태에서는 수동 카메라를 유지하며 패널 너비나 열림 상태가 바뀌면 다시 맞춘다. 패딩 변경으로 지도 도형을 재생성하지 않는다. 지도 버튼·범례·상태와 카카오 로고·축척도 열린 패널 밖으로 배치한다. 임시 도형 지도의 SVG는 읽을 수 있는 가운데 영역에 둔다.

검증은 scripts/verify-liquid-glass.mjs의 15개 화면과 E2E, 카메라·지도 입력 회귀를 사용한다. 추가 scripts/verify-desktop-glass.mjs는 실제 카카오 지도 위에서 지도 너비, 배경을 잠깐 숨겼을 때 사이드바 픽셀 변화, 양산 13개 도형의 패널 밖 가시성, 줌 버튼과 카카오 로고 가시성을 검사한다. 사용 통계 이벤트는 기록하지 않는다. 참고 사이트 데이터·숫자는 누리맵에 복사하지 않는다.
