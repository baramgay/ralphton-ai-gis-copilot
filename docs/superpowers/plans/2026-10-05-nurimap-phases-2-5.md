# 누리맵 2·3·4·5차 구현 계획

> **For agentic workers:** 사용자의 명시적 병렬 진행 요청에 따라 아래 독립 작업을 병렬 수행한다. 같은 파일은 담당자만 수정한다.

**Goal:** 실제 질의·집계·근거 오류를 해결하고 사용자 여정과 성능을 검증한다.

**Architecture:** 기존 Next.js·React 분석 앱, Supabase 게시 자료와 Vercel 운영 구성을 유지한다. UI, 분석 라이브러리, RAG를 분리해 수정하고 root가 통합·측정·배포한다.

**Tech Stack:** Next.js 16.2.10, TypeScript, Vitest, Playwright, Supabase, Vercel.

## 작업 A: UX와 공유 (ux)

- [x] 키보드·닫힌 패널·검색·빈 내보내기·비교 공유 오류를 회귀 테스트로 재현한다.
- [x] `copilot-app.tsx`, 관련 CSS·공유 모듈과 UI/E2E 테스트를 최소 수정한다.
- [x] 전체 순위 번호와 검색 범위를 CSV·보고서에 유지한다.
- [x] 관련 테스트·타입·범위 린트를 실행하고 편집을 중지한다.

## 작업 B: 분석 정확성 (analysis_data)

- [x] 지역·단위 누락, 잘못된 분모와 분기 추세를 독립 산술 테스트로 재현한다.
- [x] 통계·추세·집계·카탈로그·NH 어댑터와 해당 테스트를 수정한다.
- [x] 분모 누락 시 자료 부족을 반환하고 실제 원자료가 있을 때만 자료 파일을 재생성한다.
- [x] UI에 필요한 실제 관측월 계약을 root에 전달한다. UI 파일은 수정하지 않는다.
- [x] 관련 테스트·타입·범위 린트를 실행하고 편집을 중지한다.

## 작업 C: RAG 품질과 성능 (ops)

- [x] 관련·무관·무근거 질의 평가와 인용 문맥 일치 테스트를 추가한다.
- [x] RAG 모듈과 관련 API·테스트를 수정하며 기존 관련 질문 성능을 유지한다.
- [x] 동일 표본의 수정 전후 p50·p95·검색 품질을 기록한다.
- [x] 반복 문서 계산을 최적화하고 원격 실패·지연 경로를 검증한다.
- [x] 관련 테스트·타입·범위 린트를 실행하고 편집을 중지한다.

## 통합·4차 검증·5차 최적화 (root)

- [x] 분석 관측월 계약과 UI를 통합하고 독립 리뷰로 중요 결함을 해결한다.
- [x] 사용자 여정·수치·근거·성능을 재현 가능한 검증 스크립트와 보고서로 남긴다.
- [x] 전체 테스트·타입·린트·빌드·E2E와 네 화면 크기 검증을 통과한다.
- [ ] 코드 브랜치를 보관하고 도메인 연결을 보류한 배포를 검증 후 운영 승격한다.
