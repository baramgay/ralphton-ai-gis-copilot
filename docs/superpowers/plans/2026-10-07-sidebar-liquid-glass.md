# 사이드바 Liquid Glass 강화

사용자가 사이드바 유리 효과와 투명도 강화를 요청했다. 기존 데스크톱 패널은 불투명하고 모바일 시트는 85% 틴트였다. 밝은 테마는 72%, 어두운 테마는 76% 틴트로 바꾸고 28px 흐림·175% 채도·반사 광택·양쪽 가장자리 빛을 적용한다. 결과 헤더와 탭의 불투명 배경을 없애 유리 바탕을 이어 준다. 입력과 수치 카드의 기존 읽는 면은 유지한다.

글자 자체에 굴절이나 opacity를 적용하지 않는다. 패널의 보조 글자는 기존 본문 보조 색으로 올려 순검정·순백 배경의 틴트·최대 반사 합성에서도 4.5:1 이상인지 계산한다. 지도 이동 중에는 흐림을 끄고 85% 틴트로 전환한다. 고대비·투명도 감소·강제 색에서는 반사와 투명도를 제거한다.

데스크톱의 지도와 사이드바는 별도 그리드 칸이므로 투명한 사이드바 뒤로 지도가 비치지는 않는다. 모바일 시트는 지도 위에 있으므로 실제 배경 지도에 유리 효과가 적용된다. 지도 크기·카메라·패널 폭·접힘 설정은 변경하지 않는다. Apple 네이티브 재질의 웹 근사 표현이다.
