# 경남 누리맵 사용성·Liquid Glass 개선

**Goal:** 경상남도 특화를 첫 화면에서 인지하고, 글자·버튼·패널 크기를 개선하며 유리 재질을 강화한다.

**Design:** 주요 본문은 15px, 보조 정보는 13px 이상을 기준으로 한다. 주요 조작은 44px 이상의 클릭 높이를 확보한다. 데스크톱 기본 조작 패널은 336px, 결과 패널은 392px로 넓히며 지도 공간과 기존 저장 배치를 유지한다. 상단에 경상남도 정체성을 상시 표시하고 대표 질문에 실제 경남 지역을 사용한다.

유리 재질은 상단 탐색·부유 조작·모바일 시트에 적용한다. 텍스트가 많은 결과는 높은 불투명도를 유지한다. 광택·테두리 반사·입체 그림자와 제한된 SVG 굴절을 활용하며, 글자는 필터 밖에 둔다. 지도 이동 중·고대비·투명도 감소에서는 효과를 끄고, 동작 감소에서는 이동 호버를 끈다. Apple의 네이티브 렌더러와 동일하다고 주장하지 않는다.

**References:** [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [LeonardSEO SVG approach](https://github.com/LeonardSEO/liquid-glass-react), [dpawlikowski CSS approach](https://github.com/dpawlikowski/liquid-glass). 원본 라이브러리를 설치하지 않고 기존 CSS와 로컬 SVG로 구현한다.

## 구현과 검증

Aside CLI를 1.26.916.1741에서 1.26.1003.2338로 갱신하고 공식 `aside mcp`를 Codex의 활성 stdio 서버로 등록했다. 실제 MCP initialize·tools/list·repl 호출로 지역 표시, 분석 설정 열기와 자료 선택 창을 확인하고 스크린샷을 평가했다. 사용자의 다른 탭은 변경하지 않았다.

상단의 경상남도 표시는 로딩 전후·모바일에서도 유지한다. 스냅샷에서 직접 계산한 305개 읍면동·22개 시군구 범위를 표시한다. 김해·진주·창원·양산 질문 예시를 제공하며 원래 질문 처리 경로를 유지한다. 기본 패널 폭은 336/392px이며 기존 저장 폭·접힘 설정을 보존한다.

본문과 보조 글자를 키우고 주요 버튼의 44px 높이를 유지했다. 새 유리 표현은 기존 대비 하한을 지키는 틴트, 반사 테두리와 그림자, 미세한 호버를 사용한다. 로컬 2,664바이트 SDF 이미지와 SVG displacement 필터는 지도 상단 칩의 장식 층에만 적용해 글자를 왜곡하지 않는다. 라이브러리·런타임 canvas·외부 CDN·새 유료 기능은 추가하지 않았다. 수학적으로 생성한 자산이며 참고 저장소의 코드를 복사하지 않았다.

Chromium에서 체크무늬 배경의 같은 장면을 SVG 효과만 켜고 끄며 렌더링 차이를 시각 확인했다. 이는 웹 근사 표현이며 Apple의 네이티브 적응형 렌더러와 동일하지 않다. URL backdrop 필터의 실제 지원은 브라우저마다 다르므로 기본 흐림·틴트를 별도 층으로 유지한다. Safari·Firefox 실행 검증은 수행하지 않았다.

관련 단위 검사 113개, 브라우저 E2E 34개와 프로덕션 빌드·타입 검사가 통과했다. 변경 파일 lint는 오류 0개·기존 이미지 요소 경고 1개였다. 320/390/768/1280/1440px × 밝은/어두운/고대비 15개 조합에서 지역 표시·44px 버튼·336/392px 기본 폭·15px 자료 설명·모달 viewport·가로 넘침을 검사했다. 실제 hover에서 동작 감소의 transform이 none이며, 지도 이동과 투명도 감소를 동시에 적용해 흐림·굴절을 끄고 투명도를 줄인 기본 면을 유지함을 확인했다. 자동 Chromium UI 검증은 익명 사용 이벤트를 가로채 운영 통계를 늘리지 않는다.

재현: 실행 서버를 `UX_VERIFY_URL`로 지정하고 `node scripts/verify-liquid-glass.mjs`를 실행한다. 전체 동선은 `npx playwright test`, 지도 운영 확인은 `node scripts/verify-intuitive-production.mjs`를 사용한다. 검증 결과와 이미지 경로는 gitignored `logs/`·`test-results/`이며 로그인·인증 정보는 문서에 저장하지 않는다.
