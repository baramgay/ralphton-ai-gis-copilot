# Pretendard 적용과 화면 검증

운영 앱의 본문은 시스템 폰트였고 Pretendard 파일과 font-face 선언이 없었다. 보고서의 폰트 이름 선언만으로 앱에 적용된 상태라고 판단할 수 없다.

공식 Pretendard Variable 1.3.9의 수정하지 않은 동적 서브셋 92개를 로컬에 보관하고 SIL OFL 1.1과 출처를 함께 보존한다. 본문 첫 폰트로 적용하며 font-display: swap을 사용한다. 전체 2,957,724B를 미리 로드하지 않고 표시하는 문자의 unicode-range에 해당하는 파일만 받는다. 실제 파일의 문자표에서 한글 완성형 11,172자와 ASCII 95자의 지원을 확인했다. 기존 UI에서 사용하는 400~900 굵기도 가변 축 범위 안에 있다.

- [x] 프로덕션 빌드·타입 검사·E2E 36개 확인
- [x] 320·390·768·1280·1440px × 밝음·어두움·고대비의 15개 화면 확인
- [x] push 후 운영 SHA와 실제 렌더링 폰트 확인

Chromium CSS.getPlatformFontsForNode로 제목과 자료 선택 모달의 실제 사용 폰트가 Pretendard Variable이고 isCustomFont=true임을 확인했다. 버튼 높이, 패널 너비, 모달 화면 경계, 가로 넘침과 실행 오류도 검사한다. 검사 스크립트는 scripts/verify-liquid-glass.mjs이며 사용 통계 이벤트는 수집하지 않는다.

카카오 배경 지도 타일의 글자는 이미지이며 앱 폰트를 상속하지 않는다. 별도 PDF/HWP와 독립 SVG 시설 핀의 폰트는 이 변경으로 포함하거나 바꾸지 않았다.

운영 코드 커밋 85ac33a1d3c65fbb47b1ba3dcdc5a3f38a8e0f77과 /api/health의 commitSha가 일치했다. 운영 15개 화면에서도 제목과 자료 선택 모달의 실제 폰트가 Pretendard Variable로 확인됐고, 실행 오류·가로 넘침·화면 밖 모달은 0건이었다. 이 화면 흐름에서 받은 폰트는 9~10개 서브셋, 232,828~259,376B였으며 전체 92개를 내려받지 않았다.

GitHub CI에서 단위 검사 2,262개 통과·플랫폼 조건에 따른 8개 생략, 타입·lint·빌드·수치 336,002개 검증·고정 한국어 RAG 게이트·E2E 36개가 통과했다. 로컬 Windows 전체 단위 검사 실행은 PowerShell CLIXML 처리 문제로 완료되지 않아 CI의 완료된 결과를 기준으로 기록한다. 변경된 지도 회귀 3개와 로컬 E2E 36개·타입 검사는 별도로 통과했다. 전역 로컬 lint는 오류 0개이며 기존·검증 산출물 경고 51개를 포함한다.

main CI 37581870721은 verify와 smoke-prod 모두 성공했다. 검증 기록만 추가하는 후속 커밋은 실행 코드와 폰트 파일을 변경하지 않는다.
