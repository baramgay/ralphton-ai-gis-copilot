# 누리맵 질문·결과 작업 화면 개편

승인된 방향은 질문을 지도 밖 상단 작업 영역에 두고, 결과를 순위·선택 지역·분석 근거 세 탭으로 나누는 것이다. 지도는 질문과 결과를 공간적으로 확인하는 영역으로 사용한다. 비교와 내보내기는 직접 접근할 수 있게 한다.

1. 질문 작업 영역의 분리, 결과 탭의 접근성·키보드 이동, 비교 접근 회귀 테스트를 먼저 작성하여 실패를 확인한다.
2. 기존 계산과 공유 경로는 그대로 두고 JSX 구획을 이동한다. 질문 실행과 저장 버튼에는 읽을 수 있는 이름을 표시한다.
3. 화면 구조에 맞춰 모바일 시트, 데스크톱 패널, 테마 표면과 대비를 조정한다. 첫 결과에서 첫 두 행이 보이도록 헤더를 줄인다.
4. UI 테스트·타입 검사·린트를 실행하고 390/768/1280/1440 화면에서 질문, 순위, 지도 선택, 비교, 내보내기, 공유, 키보드 이동을 검증한다.

계산 수식·원본 순위·검색 범위·빈 결과 내보내기 차단·출처·합성 경고·공유 복원은 보존한다. 커밋과 배포는 통합 담당이 수행한다.
